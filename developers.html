A REST API on the RapidAPI marketplace, and a 24-tool MCP server for AI agents — both serving dossiers, prosecution, and a legal-intelligence layer from USPTO public data.

🔌 REST API (RapidAPI)

17 endpoints, metered in Credits, with a free tier. POST a US patent number and go.

  -H 'X-RapidAPI-Key: KEY' \
  -d '{"patentNumber":"US8724622B2"}'
